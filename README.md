# Quantum Comp

Projeto de página institucional/educacional sobre computação quântica, desenvolvido em HTML, CSS e JavaScript. O objetivo é apresentar conceitos fundamentais da tecnologia quântica de forma visual, acessível e moderna, com navegação em várias páginas e uma proposta de experiência imersiva.

## Visão geral

O site explora temas como:

- introdução à computação quântica;
- qubits, superposição e emaranhamento;
- inteligência artificial quântica;
- funcionamento da tecnologia;
- aplicações práticas;
- visão do futuro;
- maquete/protótipo de apresentação.

A estrutura do projeto foi pensada para funcionar como uma feira de ciências / apresentação digital, com abordagem didática e visual forte.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery
- Fontes externas (Poppins / Sen)
- Ícones do Lucide

## Como executar localmente

Você pode abrir o arquivo `index.html` diretamente no navegador, mas para uma experiência mais fiel ao projeto, é recomendável usar um servidor local.

### Opção 1: abrir diretamente

- Clique em `index.html` no navegador

### Opção 2: via servidor local

```bash
cd Quantum-Comp
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```
